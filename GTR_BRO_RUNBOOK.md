# GTR BRO — рабочий регламент

Голосовой проводник по nightlife внутри GTR. Активатор — центральная
кнопка **GTR** в нижней панели. Пока фича выключена, кнопка ведёт на
экран «Сегодня», как раньше.

---

## 1. Что нужно, чтобы он заговорил

Два условия, оба обязательные.

**Ключ OpenAI — секретом воркера.** Cloudflare Workers не читают `.env` и
`.env.local` в рантайме, поэтому ключ живёт только так:

```
cd /home/user/gtreventhub
CLOUDFLARE_API_TOKEN=… CLOUDFLARE_ACCOUNT_ID=… \
  npx wrangler secret put OPENAI_API_KEY --name gtr-event-hub
```

Проверка (значение не печатается, только список имён):

```
npx wrangler secret list --name gtr-event-hub
```

**Флаг в KV.** Ключ `setting:flags`, поля:

| поле | смысл |
|---|---|
| `broEnabled` | включает фичу |
| `broKill` | рубильник: гасит фичу, даже если `broEnabled: true` |
| `broRoles` | список ролей, которым фича доступна; пустой = всем |

Включить на проде:

```
npx wrangler kv key put --remote \
  --namespace-id a26fc466919d43e4a2e684d8765810b8 \
  --config .output/server/wrangler.json \
  "setting:flags" '{"broEnabled":true,"broKill":false,"broRoles":["gtr","organizer"]}'
```

Выключить мгновенно (рубильник, без деплоя):

```
npx wrangler kv key put --remote --namespace-id a26fc466919d43e4a2e684d8765810b8 \
  --config .output/server/wrangler.json \
  "setting:flags" '{"broEnabled":true,"broKill":true}'
```

Рубильник действует на обе ручки — и на создание сессии, и на инструменты.
Уже открытая сессия доживёт до своего таймаута (максимум 8 минут), новые
не начнутся.

## 2. Как устроено

```
кнопка GTR
  → BroOverlay (src/gtr/bro/BroOverlay.tsx)
      → BroSession (src/gtr/bro/session.ts)
          → POST /api/gtr-bro-session  → эфемерный секрет (10 мин)
          → WebRTC напрямую к OpenAI Realtime (звук + канал oai-events)
          → вызов инструмента → POST /api/gtr-bro-tool → KV афиши
```

Ключ есть только на сервере. Браузер получает `clientSecret`, который
годен на одно соединение и живёт десять минут.

Модель: `gpt-realtime-2.1`. Голоса: cedar, marin, ash.
Расшифровка речи пользователя включается явно (`audio.input.transcription`,
`gpt-4o-mini-transcribe`, язык ru) — по умолчанию она выключена, и без неё
панель разговора показывала бы только реплики BRO.
Параметра `safety_identifier` ручка выдачи эфемерных секретов не принимает
и отвечает на него ошибкой — его здесь нет намеренно.
Промпт: `src/gtr/bro/prompt.ru.ts`, версия в `PROMPT_VERSION` — менять
характер надо там и нигде больше.

## 3. Границы, которые нельзя двигать

**Афиша только из инструментов.** `search_events` — единственный законный
источник текущих событий. Демо-провайдера нет намеренно: за выдуманный
вечер поедет живой человек.

**Незнание называется незнанием.** Наличие мест и цены не подключены —
инструменты возвращают `availability_status: "unknown"`, живой статус
площадки возвращает `null` и `verification_status: "unknown"`. Карточка на
экране пишет это прямо.

**Карточки — только из типизированных результатов.** Ничего не
разбирается обратно из произнесённого текста.

**Подтверждения.** `NEEDS_CONFIRM` в `session.ts` — набор инструментов,
которые не выполняются до нажатия в интерфейсе. Сейчас он пуст: в MVP нет
ни одного write-действия. Первый же инструмент, который тратит деньги,
бронирует, зовёт транспорт или отдаёт геолокацию третьей стороне, обязан
попасть в этот набор вместе с человеческим описанием того, что произойдёт.
Голосовое «да» этой границы не проходит — на это есть тест.

**Чужой текст не становится инструкцией.** Названия и описания из внешних
источников проходят через `clean()`: обрезаются и лишаются ```, `<system>`,
`<instructions>`.

## 4. Ограничители расхода

| что | значение | где |
|---|---|---|
| сессий на пользователя | 30 за 10 минут | `api.gtr-bro-session.ts`, KV `brorate:<email>` |
| жизнь эфемерного секрета | 600 с | там же |
| тишина → разрыв | 90 с | `IDLE_MS` в `session.ts` |
| максимум одной сессии | 8 мин | `MAX_MS` там же |
| таймаут инструмента | 8 с | `api.gtr-bro-tool.ts` |
| событий в ответе инструмента | не больше 8 | `search_events` |

Закрытие оверлея и уход со страницы всегда рвут соединение и глушат
микрофон.

## 5. Что видно в метриках

Счётчики агрегируются по дням в KV `brostat:ГГГГ-ММ-ДД`. Ни реплик, ни
аудио, ни текста пользователя там нет — только имена событий и числа.

```
npx wrangler kv key get --remote --namespace-id a26fc466919d43e4a2e684d8765810b8 \
  --config .output/server/wrangler.json "brostat:2026-08-16"
```

Имена: `bro.session.start`, `bro.session.connected`, `bro.session.stop.*`,
`bro.session.dur.<N>m`, `bro.mic.denied`, `bro.bargein`, `bro.tool.<имя>`,
`bro.error.api`, `bro.mode.*`, `bro.voice.*`, `bro.confirm.yes|no`,
`bro.voicelab.run`.

Здоровье читается по трём отношениям: `connected/start` (доходит ли
соединение), `mic.denied/start` (не отпугивает ли запрос микрофона),
`error.api/connected` (стабилен ли провайдер).

## 6. Разбор неполадок

| симптом | причина | что делать |
|---|---|---|
| кнопка GTR ведёт на «Сегодня» | `broEnabled` выключен или нет ключа | §1 |
| «Голос не настроен на сервере» | 503 `no-key` | положить секрет, §1 |
| «GTR BRO пока выключен» | 503 `flag` или `kill` | §1 |
| «Слишком много запусков подряд» | 429, лимит 6/10 мин | подождать или поднять `RATE_MAX` |
| «Микрофон закрыт» | пользователь отказал | разрешить в настройках сайта; на iOS нужен HTTPS |
| 502 upstream | провайдер ответил ошибкой | статус в логах воркера: `wrangler tail --name gtr-event-hub` |
| голос молчит после старта | канал `oai-events` не открылся | смотреть состояние в шапке оверлея; «поднимаю связь» дольше 15 с = сеть |
| говорит поверх пользователя | перебивание не сработало | `bargeIn()` глушит трек локально на 120 мс; проверить, что событие `input_audio_buffer.speech_started` приходит |

Логи воркера намеренно не содержат ни ключа, ни тела чужой ошибки —
только статус.

## 7. Режимы управления

**Рация (по умолчанию).** Микрофон открыт только пока палец на кнопке:
зажал — говоришь, отпустил — реплика ушла целиком и BRO отвечает. Серверный
детектор речи в этом режиме выключен (`turn_detection: null`): конец
реплики определяет палец, а не тишина — в шумном клубе детектор слышит
толпу, а не человека. Зажать во время ответа — перебить. Касание короче
250 мс считается промахом и не отправляется.

**Свободно.** Классический режим с серверным VAD: BRO слышит сам,
перебивание голосом. Хорош в тихом месте, бесполезен на танцполе.
Переключение — в настройках оверлея, на живой сессии применяется
перезапуском.

## 8. Voice Lab

Доступен BOSS в настройках оверлея. Прогоняет пять одинаковых реплик
выбранным голосом (`VOICE_LAB_LINES` в `prompt.ru.ts`), чтобы сравнивались
голоса, а не тексты. Реплики произносятся дословно.

## 9. Проверки

```
npm test                 # 20 тестов: промпт, инструменты, граница подтверждений
npx tsc --noEmit -p tsconfig.json
```

Что закрыто тестами: границы безопасности присутствуют во всех трёх
режимах, режимы действительно различаются, контекст не протекает пустыми
полями, инструменты не выдумывают несуществующие площадки, наличие мест
всегда `unknown`, чужие заголовки лишаются управляющих конструкций,
`NEEDS_CONFIRM` не может содержать запись без описания для человека.

Что проверено на живом API: ключ действителен, модель `gpt-realtime-2.1`
принимается, наш ровно тот же конфиг сессии (инструкции + инструменты +
расшифровка + голос) возвращает настоящий эфемерный секрет. Обе ручки на
проде отвечают 401 без входа.

Что тестами и проверками не закрыто: сам голосовой разговор — микрофон,
качество звука, задержка ответа, поведение перебивания на реальном
устройстве. Браузер в среде разработки в сеть не выпущен, поэтому этот
прогон делается руками на телефоне.
