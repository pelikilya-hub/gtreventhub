# GTR Event

Операционная платформа площадок Пхукета: конструктор события с живым
контролем, смета с комиссией GTR, каталоги площадок (97), артистов (312),
подрядчиков и оборудования, витрина организатора.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000 → /gtr
```

Демо-вход: кнопки ролей на экране входа, пароль `gtr2026`
(pr@ / owner@ / sales@ / admin@gtr.events).

## Стенд

https://gtr-event-hub.netlify.app/gtr/login — Netlify, серверный рантайм
(SSR + серверные функции через пресет `netlify` в `netlify.toml`).

Работает и как мобильное приложение: адаптив до 860px + PWA
(`manifest.webmanifest`, установка на главный экран телефона).

### Переменные окружения (Netlify → Environment variables)

- `GTR_ACCESS_PASSWORD` — пароль входа на стенде. Задан → демо-режим
  (пароль `gtr2026`, кнопки быстрого входа) отключается, вход только по
  этому паролю. Не задан → демо-режим, годится только для локалки.
- `GTR_SESSION_SECRET` — подпись сессионной cookie, на проде обязателен.
- `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` — уведомления о заявках
  организаторов (см. `.env.example`). Без них заявки работают, но
  уведомление не уходит.

### Деплой из Claude Code / CI-песочницы

Node `fetch` не читает `HTTPS_PROXY` сам — деплой-команда Netlify MCP
падает с 403 на сетевом уровне. Лечится префиксом:

```bash
NODE_USE_ENV_PROXY=1 npx -y @netlify/mcp@latest --site-id <id> --proxy-path "<из deploy-site>"
```

## Стек

React 19 · TanStack Start/Router (SSR + серверные функции) · Nitro ·
без UI-библиотек (дизайн-система GTR: Oswald / Golos Text /
JetBrains Mono, тёмная тема #0A0B0D, акцент #E5231B, геометрия 90°,
trash polka анимации).

## Структура

- `src/gtr/` — приложение: данные, стор, экраны, редактор контента
- `src/gtr/data/` — базы: площадки, артисты, подрядчики с пакетами,
  оборудование и интерактив, ставки площадок с провенансом
- `src/routes/gtr/` — маршруты (вход, кабинеты, витрина организатора)
- `public/fonts/gtr/` — самохостящиеся шрифты
