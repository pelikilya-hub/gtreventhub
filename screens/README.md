# Скриншоты GTR Event

Сняты с локального стенда (`npm run dev` → `http://localhost:3000/gtr`),
демо-вход ролью «GTR-админ» — видны все разделы сети.

Десктоп: Chromium 1600×1000, full page. Мобильные: iPhone-профиль 390×844.
Формат — JPEG (исходники снимались в 2× и ужаты вдвое).
