# Пригласительные посты для WhatsApp

Разметка WhatsApp: `*жирный*`, `_курсив_`, `~зачёркнутый~`. HTML не работает.
Превью подтягивается только с **первой** ссылки — поэтому ссылка на приложение
идёт одна и отдельной строкой. Эмодзи в начале строк держат ритм при пересылке.

## Как отправлять

1. Скопируй блок целиком — звёздочки станут жирным сами.
2. Первой уходит ссылка на приложение: превью будет с неё. Ссылку на Telegram
   ставь ниже, иначе превью подтянется с неё.
3. В *Статус* лучше короткий вариант (2) — длинный текст там обрезается.
4. Фирменные стикеры GTR для WhatsApp уже собраны — их можно слать следом,
   они узнаются лучше любого баннера.

## Чего в постах сознательно нет

- Обещания купить билет в приложении: покупки пока нет, и врать в приглашении
  нельзя — человек откроет и не найдёт.
- Слова «лучшая» и «№1»: это спорный маркетинг, а у нас проверяемые цифры.
